# 캐릭터 시트 템플릿 일치 감사

기준 템플릿은 첨부된 파우스트 시트의 1536×1024 가로 구성입니다. 파일 크기만으로 구성 일치를 단정하지 않고, 전신 3면도·6종 표정·손동작·세부 확대·의상 레이어·소품·팔레트가 한 장에 있는지 확인해야 합니다.

감사 기준일: 2026-11-20

- 전체 캐릭터·집단·변형 항목: 90개
- 1536×1024 파일: 32개
- 파일 크기가 템플릿과 다른 항목: 58개
- 재작성 필요: 58개. 단, 1536×1024인 일부 제2부 집단 시트도 구성 요소가 축약되어 있어 시각 검수가 추가로 필요합니다.

재작성 대상은 `reference-index.json`의 `image`와 실제 파일 크기를 대조해 관리합니다. 작은 단일 컷, 가로 띠형 시트, 2~4컷 조합 시트는 템플릿 불일치로 분류했습니다. 기존 인물의 얼굴·머리·의상·소품은 유지하고, 첨부 템플릿의 배치와 정보량으로 다시 제작해야 합니다.

공개 페이지의 기술 자료는 접힌 영역으로 유지하며, 화면에 보이는 설명은 기획 의도와 인물 소개 중심으로 제공합니다.

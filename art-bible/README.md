# 파우스트 제1부 시각 설정집 — 제작 기준

- 범위: Project Gutenberg #2229, 제1부 전체(헌시·서막·천상 서곡·환상극 포함).
- 첨부 파우스트·메피스토펠레스 시트를 인물 외형 및 한국 웹툰 화풍 기준으로 사용한다.
- 원문 등장인물명과 별칭을 대조한다. Margarete/Gretchen은 동일 인물이다.
- 군중의 번호 배역은 원문 장면과 함께 식별한다. ALLE 등 대사 합창 표기는 독립 인물로 세지 않는다.
- 이름만 언급된 사람, 실제 등장 배역, 합창단/종족, 환상극의 의인화를 구별한다.
- 얼굴 정면·측면·후면, 전신 3면도, 표정, 손, 의상 레이어, 소품, 팔레트를 개별 인물 시트에 포함한다.
- 원문이 정하지 않은 나이·키·뿔·복식 장식은 '시각화 설정'으로 표시한다.
- Faust의 노학자 모습과 회춘 이후 모습은 동일 인물의 변형 시트로 관리한다.
- 장소별 시트: 주요 시점의 컨셉, 평면/배치 지도, 동선, 출입구, 주요 소품, 낮/밤 조명, 팔레트. 지도에는 '연출용 가상 배치도 · 축척 없음'을 명시한다.
- 실제 등장 장소와 대사로만 언급된 지명은 분리한다. 같은 장소 재등장은 통합하고 조명/시간 변형을 추가한다.

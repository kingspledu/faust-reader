# 11장 대화·문체 시범본 검토

조회·작성일: 2026-11-18, 한국 시간. 이번 작업은 11장 전체 21장면의 검토용 수정이다. 공개 본문·독일어 원문·대응 번역·삽화·TTS는 교체하지 않았다. 앞서 만들기 시작한 다른 장의 대사 초안도 적용하지 않았다.

## 오픈소스 선택 근거

GitHub 공식 API에서 `humanizer in:name,description`을 별 수 내림차순으로 조회했다. 첫 조회에서 [blader/humanizer](https://github.com/blader/humanizer)는 70,255개로 조회 결과 중 가장 많았다. 최종 재조회 시 70,258개였다. 실제 사용자·설치 수를 뜻하지 않으며 GitHub 전체의 모든 유사 도구를 빠짐없이 비교했다는 뜻도 아니다.

|저장소|첫 조회 별 수|용도·선택 판단|
|---|---:|---|
|[blader/humanizer](https://github.com/blader/humanizer)|70,255|AI 문체를 다듬는 편집 스킬. 주 참고 자료로 선택|
|[op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)|23,096|중국어판이므로 한국어 집필의 직접 기준으로 쓰지 않음|
|[epoko77-ai/im-not-ai](https://github.com/epoko77-ai/im-not-ai)|6,624|한국어 번역투·피동·기계적 병렬·어휘 치환 주의점을 보조 참고|
|[lynote-ai/humanize-text](https://github.com/lynote-ai/humanize-text)|3,516|별도 재작성 도구. 이번 작업에서는 실행하지 않음|

검색 상위에 포함된 .NET의 Humanizr/Humanizer는 문자열·날짜 표시 라이브러리라 제외했다. 표절·탐지 회피나 오디오 워터마크 도구도 요청한 소설 문체 편집과 목적이 달라 제외했다.

주 자료는 [Humanizer SKILL.md](https://github.com/blader/humanizer/blob/b48c832f0f809c1b5658edbb838c2521b72f2413/SKILL.md), 버전4.0.0, 커밋 `b48c832f0f809c1b5658edbb838c2521b72f2413`, MIT 라이선스다. 이 프로젝트에는 참고 문서와 라이선스 사본만 보관했다. 프로그램 설치·외부 모델 호출·AI 탐지기 실행은 하지 않았다. Markdown 편집 지침을 읽고 집필·수정·원문 재대조에 적용했다. 한국어 보조 자료의 다중 에이전트·자동 게이트 파이프라인 전체를 실행한 것은 아니다.

## 이번 글에 적용한 원칙

- 대사가 이미 보여 준 감정을 나레이션·독백에서 다시 설명하지 않는다.
- 문단마다 의미를 정리하거나 교훈을 붙이지 않는다. 행동·반응·다음 대사로 이어 간다.
- ‘자신의 작음’, ‘그 태도의 의미’처럼 추상적으로 돌려 말하지 않고, 무엇을 보고 왜 망설이는지 쓴다.
- ‘그는…그는…’ 식의 반복과 같은 길이의 문장을 줄인다. 긴 설명과 짧은 대사의 호흡을 섞는다.
- 번역 문장의 어순과 호칭을 그대로 가져오지 않는다. 파우스트는 자연스러운 반말을 쓴다. 사용자의 후속 요청을 반영해 이번 시범본의 메피스토도 느긋한 반말로 바꿨다. 상대를 살피며 놀리고, 혼자 상황을 즐기는 태도를 살린다. 특정 작품의 대사나 어휘를 복제하지 않는다.
- 자연스럽게 보이려고 새 사건이나 대화 상대를 만들지 않는다. 혼자 있는 그레첸·파우스트 장면은 그대로 둔다.
- 영어 지침의 인용부호 규칙은 한국어 소설에 기계적으로 적용하지 않는다. 대사 ‘“ ”’와 마음속 말 ‘‘ ’’의 기존 구분을 유지한다.
- 단어를 금칙어 목록처럼 치환하지 않는다. 앞뒤 대화와 행동을 함께 읽고 문단 전체를 다시 쓴다.

## 장 전체 검토 결과

11장을 선택한 이유는 두 사람이 함께 있는 대화 장면과 혼자 생각하는 장면을 모두 시험할 수 있기 때문이다. 혼자 있는 장면에까지 티키타카를 넣으면 원문 사건이 달라진다.

|검토 항목|현재 공개본|시범본|
|---|---:|---:|
|삽화 장면|21|21|
|따옴표로 표시한 발화 문단 수|12|21|
|이름이 붙은 마음속 독백|21|3|

발화 수는 독백·혼잣말을 포함하는 서식 지표이며, 대화 품질이나 실제 화자 교대 횟수를 뜻하지 않는다. 원문에 있는 2번 장면과 10~14번 장면의 주고받기를 직접 대사로 살렸다. 의문과 응답을 나누되, 파우스트가 원문에 없던 거절을 명확하게 선언하거나 메피스토에게 허락을 받으라고 요구하는 새 발언은 넣지 않았다.

### 구체적인 수정

현재: ‘메피스토는 자신이 얼마나 애썼는지 늘어놓으며 파우스트를 재촉했다.’

수정: ‘“설마 이게 아까운 건 아니겠죠? 제가 얼마나 애썼는데요.” 그는 더 기다리지 않고 수납장을 열어 상자를 넣었다.’

원문의 재촉을 말로 들려주고 실제 행동으로 잇는다. 그 직후 같은 뜻의 독백은 붙이지 않는다.

현재: ‘그녀를 천사 같다고 여기며 한동안 빈 침대를 바라보았다.’

수정: ‘잠깐 마주친 것밖에 없으면서, 그녀가 어떻게 자랐을지까지 궁금해졌다.’

파우스트의 이상화는 남기되, 문어적인 수식을 줄이고 그가 무엇을 생각하는지 쉽게 전달한다.

### 원문 의미·행동 대조

1. 그레첸이 머리를 묶고 낮의 남자를 떠올리다가 나간다.
2. 파우스트와 메피스토가 들어오고, 파우스트의 요청으로 메피스토가 나간다.
3. 파우스트가 방·의자·가족의 모습을 떠올린다. 어린 시절 장면은 사실로 확정하지 않고 상상으로 서술한다.
4. 침대 커튼을 들고, 자기 행동을 돌아보며 그레첸이 들어올 상황을 걱정한다.
5. 메피스토가 돌아오는 그레첸을 보고 재촉한다. 파우스트는 떠나려 한다.
6. 보석 상자를 내밀고, 망설임을 보석에 대한 미련으로 몰아가는 대화를 한다.
7. 메피스토가 상자를 넣고 잠금쇠를 누른다. 두 사람은 떠난다.
8. 그레첸이 등불을 들고 돌아와 창문을 열고 어머니를 기다린다.
9. 옷을 갈아입으며 툴레의 왕 노래를 부른다. 금잔은 연인의 선물이며 마지막에 바다에 던져진다.
10. 옷을 넣으려 수납장을 열고 상자를 발견한다. 담보로 맡긴 물건일 가능성을 생각한다.
11. 열쇠로 상자를 열고 보석을 해 본다. 거울 앞에서 돈에 따라 달라지는 대우를 생각한다.

독일어·대응 번역의 문자열과 순서, 삽화21개의 경로와 순서, 기본 접기 상태를 자동 대조했다. 사람의 자연스러움 평가는 아직 받지 않았다. AI 탐지 점수로 ‘사람이 쓴 글’임을 보증하지 않는다. 자동 검사는 보존과 배치에 관한 것이며 문학적 자연스러움의 합격 판정은 아니다.

## 검토 파일

후속 말투 수정: 2번과 10~14번 장면의 메피스토 발언을 모두 다시 확인했다. ‘킬킬킬’ 같은 웃음소리 표기는 넣지 않고, 파우스트의 굳은 표정을 보고 웃거나 대답을 기다리지 않고 행동하는 모습으로 장난기와 무심함을 드러냈다. 평소 반말과 달리 일부러 존댓말로 놀리는 연출은 필요할 때만 검토하며 이번 짧은 시범 장면에는 억지로 추가하지 않았다.

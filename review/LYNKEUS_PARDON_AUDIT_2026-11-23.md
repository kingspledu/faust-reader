# 륀케우스 사면·보물 제안 검수

두 배치 32컷을 파우스트·헬레네·륀케우스·시종·성 안뜰의 원본 시트 다섯 장과 직접 대조했다.

- 첫 원본의 비균등 배열을 발견해 게시하지 않고 균등한 4열×4행으로 다시 생성했다. 프로젝트에는 최종 원본만 설치했다.
- 파우스트는 갈색 웨이브 머리·안경·면도한 얼굴·먹빛과 버건디 로브, 륀케우스는 적갈색 머리·짧은 적갈색 수염·주근깨·청회색 튜닉·갈색 망토로 구분된다.
- 헬레네의 금발·월계관·상아색 옷·버건디 망토와 붉은 천개 좌석을 유지했다. 시종들은 금발·청록 제복을 유지한다.
- 첫 배치 6번에서 사슬을 풀고 이후 두 배치에서 사슬이 다시 나타나지 않는다.
- 첫 배치의 과거 전투·약탈, 둘째 배치의 비유 속 군대·태양을 현재 사건으로 추가하지 않았다.
- 보물 상자·에메랄드·진주와 루비·카펫의 세부 구도를 인물 대화와 교차했다. 제안한 장신구를 헬레네의 기존 의상에 임의 착용시키지 않았다.
- 두 배치 모두 4×4·16개 고유 분할 파일과 접힌 원문·번역 보존 설치 검사 통과.
- 육안 검수는 보이는 외형·복식·공간·장면 흐름에 한한다. 작은 원경의 미세한 눈동자·자수나 화면 밖 신체의 완전 일치를 주장하지 않는다. 공개 파일 검사는 별도 실행한다.

32컷 추가 후 남은 이미지 없는 구간은 864개, 최소 54배치다. 기존 삽화 재작업·웹소설·TTS는 제외한다.

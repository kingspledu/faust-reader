# 대사와 독백 기준 · 현대 K드라마 말투

사용자 수정 방향: 고전 배경이라도 대사와 속마음은 지금 사람이 입으로 말할 법하게 쓴다. 쉬운 단어를 고르는 데 그치지 않고, 배우가 그 상황에서 실제로 말하는 호흡으로 다시 쓴다.

## 예시

| 이전 표현 | 바꾸는 방향 |
|---|---|
| 저렇게 성을 내는 모습은 처음이군. | 쟤가 저렇게 화내는 건 처음 보네. |
| 무엇이 자네를 그토록 괴롭히나? | 왜 그래? 무슨 일 있어? |
| 부탁이니 혼자 있게 해 주게. | 잠깐 혼자 있고 싶어. 나가 있어 줄래? |
| 모르겠네. 그래도 되나? | 글쎄. 이래도 괜찮을까? |
| 그 아이도 나를 기억하고 있을까? | 그쪽도 날 기억할까? |
| 그레트헨이 돌아오기 전에 나가야겠군. | 그레트헨 오기 전에 나가야 해. |

12장 첫 독백의 검토용 수정 예:

> 쟤가 저렇게 화내는 건 처음 보네. 보석 때문에 무슨 일 났나?

이 예시는 12장 공개본을 변경한 것이 아니다. 현재 시범 수정 범위는 11장 전체다.

## 인물 말투

- 파우스트 → 메피스토펠레스: ‘나가 있어 줄래?’, ‘빨리 나가자’처럼 익숙한 상대에게 하는 반말. 불안하거나 조급해지면 말이 짧아진다.
- 메피스토펠레스 → 파우스트: 자연스러운 해요체로 예의를 차리는 척하며 빈정거린다. 존댓말을 쓴다는 이유로 매번 ‘~하십시오·~십니까’로 말하지 않는다. 속마음은 반말이다.
- 그레트헨 독백: ‘내가 기억을 못 하나?’, ‘엄마가 받아 놓으셨나?’처럼 혼자 떠올릴 법한 말. 감정을 설명하는 보고서처럼 쓰지 않는다.
- 상대나 장면이 바뀌면 관계에 맞춰 높임말을 검토한다. 한 인물의 모든 대사를 같은 어미로 통일하지 않는다.

## 점검 방법

1. 대사만 따로 읽고, 배우가 말하면 자연스러운지 확인한다.
2. ‘~군·~일세·~하게·자네·성을 내다·헤아리다’ 등이 나오면 문맥을 다시 본다. 자동 치환하지 않고 말 전체를 고친다.
3. 사람 앞에서 하는 말과 혼자 생각하는 말의 길이·호흡을 구분한다. 독백에 완전한 설명문을 매번 넣지 않는다.
4. 누가 무슨 일을 말하는지는 분명하게 남긴다. ‘걔’, ‘그거’가 누구인지 모르면 이름이나 물건을 다시 말한다.
5. 현대적으로 쓰되 인터넷 유행어·밈·욕설·과한 드라마식 명대사를 억지로 넣지 않는다. 현대의 기기나 제도도 추가하지 않는다.
6. 말을 자연스럽게 만들려고 원문에 없는 약속·관계·새 사건을 만들지 않는다.

나레이션은 읽기 편한 과거형을 유지하고 대사와 독백은 현대 구어로 쓴다. 원문·대응 번역은 별도 보존한다. 수정안 검토 뒤 공개 반영할 때만 TTS 본문·색인·캐시 지문도 함께 갱신한다.

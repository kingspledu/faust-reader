# 잔여 기능 실행 계획 및 적합성 검토

기준: 스킬 4bc7d60 및 현재 공개 파우스트. 기존 URL·원문/번역·각색문·승인 시트·230개 개별 MP3는 보존한다.

1. 정밀 재생 엔진: 기존 timeline을 공통 계약으로 사용하고 Web Audio 예약 엔진/HTMLAudioElement 호환 엔진을 선택 가능하게 한다. pause·seek·속도 변경은 예약을 취소하고 하나의 엔진만 출력한다. 문단 안 컷·다른 문단 원래 쉼·첫/마지막 경계·4ms 감쇠·로딩 지연·잠금 복귀를 검사한다. mock sample clock과 실제 음성 청취를 별도 기록한다.
2. 전편 ID/자료맵: 84페이지의 문단에 지속 ID를 등록하고 기존 ID를 보존한다. 확정 TTS는 1·2장만 연결한다. 텍스트·공백·인용부호·그림·접기 전후 일치와 재설치 멱등성을 검사한다. 단순 순번 재발급 금지.
3. 한국어 정렬: 모델 로컬 준비 확인 후 1장 표본으로 한국어 어절 및 문자 범위 계약을 검증한다. 강제 정렬과 독립 ASR을 별도 실행하고 실제 청취 경계와 비교한다. 근거 없는 시각은 null. trim/offset/속도 이중 보정, 어휘 버튼 내부 텍스트와 문장 fallback 검사 후 2장 확대. 모델이 없으면 준비 미완료로 보고하고 시간 균등 분배나 임의 API 우회 금지.
4. 오프라인 버전 관리: 장별 예상 용량·선택 장/부·중단 재개·검증된 파일 재사용·릴리스별 완료 기록을 추가한다. 새 CORE 우선, 기존 음성 보존, 부분 실패 때 완료 금지, Range/용량 부족/삭제 범위/저장 장 목차 이동 시험. 대용량 전편 자동 다운로드 금지.
5. 전편 어휘: 한국어 독서층에서 중학생에게 필요한 용어를 장별로 선정하고 문맥 뜻을 검토한다. 원문 번역을 자동 교체하지 않는다. 카드 개수와 0개 장 보고, 하나만 열기·Escape·포커스 복원·재생 클릭 전파 방지·textContent 보존 검사.
6. 음량/청취·실기기: 설정상 1배역 1성우 검사와 실제 음색 검증을 구별한다. 대표 문장 비교 후 필요한 문장만 재생성 검토. Android/iPad의 설치·회전·잠금·이어폰·오프라인 복귀·음량을 확인한다. 장비가 없으면 미실시로 유지.

## 적합성 판단

1→3은 시계와 DOM 계약 의존 관계가 있어 순서가 적절하다. 4와 5는 기반 확정 후 독립적으로 진행할 수 있다. 실기기 검사는 마지막에만 미루지 않고 각 재생 엔진 변경 시 표본 수행한다. 모든 스킬 기능을 영어 3권 템플릿 그대로 이식하는 것은 부적절하며 파우스트의 한국어·장별 URL에 어댑트한다. 자동 시험 통과를 음질/청취 승인으로 대체하지 않는다.

## 이번 즉시 변경

오디오 play 시 원문/번역 .source-fold를 숨기고 inert로 전환한다. pause/ended/error 시 복원한다. 원문 문자열과 details의 open 선택은 보존한다. 새 문장 자동 연결 시 play 이벤트가 다시 적용한다. 이는 비교 자료 삭제나 번역문 수정이 아니다.

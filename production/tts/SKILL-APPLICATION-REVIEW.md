# 최신 오디오북 스킬 재검증과 반영 검토

검토 버전: `ebd0d9a4a8fb36e64729462c46a0eb97725f8ded`.
이전 검토의 `b0227c5` 이후 전체화면 필수 절차와 브라우저 회귀 검사가 추가됐다.

## 재검증 결과

- 최신 스킬 패키지: 115개 파일과 reader 소스 45개 무결성 통과.
- 포함된 실제 모듈: 전체화면 진입·버튼 종료·브라우저 종료 후 버튼 상태·분할 선택 보존·거부/미지원 안내 통과.
- 위 검사는 스킬이 만드는 임시 화면 검사다. 현재 파우스트 페이지에 전체화면이 구현됐다는 증거가 아니다. 오디오 currentTime 보존까지 시험하지 않으므로 이식 후 별도 검사가 필요하다.
- 현재 1장: MP3 60개 해시·바이트·본문·성우, 게시 문단 순서 보존 통과. 실제 브라우저 재생·문장 이동·속도 변경·문장 번호 복원·문단 강조 통과.
- 기존 미반영 항목은 유지된다. 전체화면·분할 배치·오프라인·정밀 이어듣기·문장 DOM 연결·음량과 경계 무음 처리·독립 ASR와 실기기 청취는 완료되지 않았다.

## 그대로 설치할 수 없는 이유

스킬의 landscape-reader.js는 article과 #floating-reader가 없으면 즉시 종료한다. 파우스트에는 article만 있고 #floating-reader는 없다. #font-size와 #font-value도 없어 기존 스크립트를 단순 연결하면 글자 조절 코드가 실패할 수 있다. section.chapter와 .reading-sentence가 없어 삽화 매핑도 구성되지 않는다. #install-app이 없으므로 전체화면 거부 시 안내도 나타나지 않는다.

스킬의 3권·29장·영어 토큰 전제를 파우스트의 장별 HTML·1부 28장·2부 구분·한국어 본문에 맞춰야 한다. 기존 본문을 새 템플릿으로 덮어쓰는 방식은 채택하지 않는다.

## 반영 결정과 순서

| 순서 | 적용 범위 | 구현·완료 기준 |
|---|---|---|
| 1 | 제작 검토와 생성 분리 | 현재 검토 JSON을 입력으로 사용하고 생성기에서 confirmed 기록을 제거한다. pending 한 건만 있어도 생성 실패. 재실행 전후 검토 파일 해시 동일. |
| 2 | 1장 문장 매핑 | source_span/source_slice와 실제 DOM 텍스트 노드를 대조해 문장 span 및 문단 ID를 부여한다. 독백·인용부호·공백·원문 접기·삽화 경로를 보존하고 본문 변경 시 오연결을 거부한다. |
| 3 | 기존 플레이어 확장 | 단일 audio 유지. manifest 지문별 문장 ID·초·속도 저장, 문장 클릭 탐색, 실제 DOM 활성 문장 이벤트 추가. 기존 문장 번호 저장값은 안전하게 이전한다. |
| 4 | 공통 화면 이식 | 파우스트 전용 선택자 대응표와 설치기를 만든다. 기본 읽기 전체에 가로/전체모드 버튼을 제공하되 오디오 없는 장에는 재생기를 만들지 않는다. 재생기·본문을 복제하지 않는다. |
| 5 | 가로·전체화면 검증 | 삽화 44%/본문 56%, 상단 32px·하단 36px 기준. 태블릿 높이 제한 없음. 전체화면 진입/종료/거부 때 트랙·초·속도·문장·분할 선택 보존. 미지원 안내 표시. |
| 6 | 음성 측정·오프라인 | 음량·무음을 먼저 측정해 적용값을 정한다. 독백 효과 이력 불명 상태에서 DSP를 추가하지 않는다. 한국어 단어 시간은 근거가 있을 때만 추가한다. 파일 검증 저장·Range·책 범위 삭제·기존 캐시 보존을 각각 시험한다. |

기존 MP3는 그대로 사용할 수 있다. 현재 음성이나 삽화를 다시 생성할 이유는 확인되지 않았다. UI 개선 때문에 MP3를 병합하거나 재인코딩하지 않는다.

## 회귀 검사 기준

1. 원문·번역·각색문 텍스트, 순서, 그림 src, 접기 상태·메뉴 구조 보존.
2. 740×360, 844×390, 932×430, 390×844 및 1024×768, 1180×820, 1366×1024. 1920×1080 수동 분할과 저장값 복원.
3. 재생 중 전체화면 전환·회전 후 같은 audio 노드와 src, 진행 시간·속도 유지. 전체화면 미지원과 거부 후 재시도 가능.
4. 장면 변경·문장 클릭·이전/다음·느린 이미지 응답에서 해당 장면 그림만 표시. reduced-motion, 스크롤 유예, 큰 글자 검사.
5. 실제 청취·모바일 잠금·이어폰 조작은 별도 기록. 자동 검사 성공을 이 항목의 성공으로 대신하지 않는다.

이번 작업에서는 검증 자료와 적용안을 갱신했다. 공개 사이트의 기능·원고·오디오는 변경하지 않았다. 최신 전체화면 테스트 결과는 `skill-fullscreen-recheck.json`, 프로젝트 대조 결과는 `skill-integration-audit.json`에 기록했다.

# 오디오북 스킬 적용 결과

기준 스킬 ebd0d9a. 공통 가로/전체화면 모듈을 1부 28장·2부 56페이지에 설치했다. 원문·번역·각색문 텍스트 및 삽화 경로 보존을 설치기에서 검사한다. 음성은 확보된 1장에만 제공한다.

- 1장 문장 ID 60개, 문단 ID 18개. 실제 문장 DOM과 대본을 대조하고 불일치 시 재생 차단.
- 단일 audio 노드 유지, 문장 강조·클릭 탐색·속도·초 단위 이어듣기. 저장 키는 manifest SHA로 분리.
- 가로 배치·전체화면 독립 전환, 거부/미지원 안내, 태블릿 높이 제한 없음. 실제 본문을 이동하며 복제하지 않음. 그림은 명시적인 기존 장면에 연결.
- 현재 장 파일을 SHA/크기로 확인한 뒤 캐시에 저장. 완료 전에는 완료 표시 없음. 온라인 응답을 우선하며 오프라인은 저장 파일만 사용. MP3 Range 206 지원, faust-saved-v1만 삭제.
- 모든 MP3 원본 유지. 10ms RMS -50dBFS 측정, 150ms 여유와 최대 1초 제한으로 바깥 무음 경계 설정. 같은 문단만 끝 무음을 건너뛰고 다른 문단은 끝까지 보존하고 350ms 쉼. 성우별 중앙 RMS 기준 감쇄만 적용. 독백 추가 DSP 없음.
- 생성기는 기존 편집 검토를 읽기만 하고 미확정 입력을 거부. 재실행 전후 검토 JSON 해시 보존. 이전 생성 명령은 이 경로로 연결.
- 원고 설치기에 공통 독서 모듈 및 오프라인 목록 재설치 연결.

실제 Chrome에서 84페이지 모듈, MP3 재생, 초/속도 복원, 동일 audio 보존, 전체화면/거부/미지원, 8개 화면 크기, 그림 전환, 오프라인 재접속·재생·Range·다른 캐시 보존을 시험했다. reader-integration-browser.json 참조.

아직 미완료: 한국어 단어별 Whisper/독립 ASR 정렬, 실제 음성 내용·연기·독백 잔향 청취, 휴대폰/iPad 잠금·이어폰 검사, PWA 설치형 manifest/아이콘. 현재 ‘설치 안내’는 안내이며 설치 성공을 뜻하지 않는다. 브라우저 음량 감쇄는 플랫폼에 따라 제약이 있으므로 실기기 청취가 필요하다. 오프라인 장 밖의 목차 링크는 저장되지 않은 장을 열지 못할 수 있다.

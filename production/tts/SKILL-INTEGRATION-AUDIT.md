# 오디오북 스킬 반영 검증

대상: kingspledu/audiobook-reader-skill commit b0227c5979198fb366962f609916d1155c81f4f7. 로컬 참조 사본을 최신 버전으로 갱신한 뒤 비교했다.

## 검증 결론

현재 사이트는 1장의 기본 문장별 재생까지 적용됐다. 최신 스킬의 전체 오디오북 독서 환경을 적용한 상태는 아니다. 이번 작업은 검증이며 미구현 기능을 추가하거나 재배포하지 않았다.

## 통과

- 스킬 패키지 무결성: 113개 manifest 파일, 45개 reader 소스 검사 통과.
- 1장 문장 MP3 60개의 파일 SHA·바이트 수·문장 ID·본문·성우와 게시 문단 순서 대조.
- Chrome 실제 MP3 재생·일시정지·이전/다음·속도 변경·문장 번호 복원·문단 강조·390px 화면 버튼 영역 검사.
- 1·2장 코드 복사 페이지: canonical renderer와 바이트 일치, SHA 검증, 실제 clipboard, 빠른 장 변경, 404·오염 파일 거부, clipboard 거부 시 수동 복사 대안 통과.
- TTS 230문장: JS 문법·색인·DSP·모의 배치 검사 통과. 독일어 원문과 번역을 낭독 대상에 넣지 않는다.

## 미반영 및 부분 반영

| 우선 | 요구사항 | 현재 상태와 근거 |
|---|---|---|
| 높음 | 생성기는 검토 상태를 자동 확정하지 않음 | build_chapter01.py 24행, build_chapter02.py 48행에서 confirmed를 기록한다. 검토 산출물과 생성기를 분리하고 생성기는 미확정 입력을 거부해야 한다. 기존 파일이 잘못된 음성이라는 뜻은 아니며 재생성 때 검토를 우회할 수 있는 구조가 문제다. |
| 높음 | 영구 DOM 문장·문단 ID | 색인에는 있으나 본문 DOM에는 연결하지 않았다. 문단 배열 순번으로 강조하므로 삽입·편집 시 오연결 위험이 있다. 본문을 보존한 명시적 ID 매핑과 변경 감지가 필요하다. |
| 높음 | 진행 상태 | 문장 번호만 저장한다. currentTime·선택 속도·manifest 해시를 저장하지 않아 문장 안 위치 복원이 없고 파일 교체 시 오래된 위치를 사용할 수 있다. |
| 높음 | 음량·경계 무음 | 화자별 음량 측정/기준, trim_start/trim_end와 문단 안 무음 건너뛰기가 없다. 재생기는 문장 파일 전체를 ended까지 재생한다. |
| 높음 | 독백 효과 이력 | ZIP은 browser_generated_cache로 표시되지만 MP3별 effects_applied 기록이 없다. 플레이어에서 추가 DSP를 걸지는 않는다. 모델 출력과 최종 독백 효과는 원본 처리 이력·표본 청취로 따로 확정해야 한다. |
| 중간 | 가로모드·전체화면 | 공통 모듈, 수동 전환, 태블릿 자동 분할, 왼쪽 삽화/오른쪽 본문, 32px/36px 바, 가로 글자 설정이 없다. 현재는 위쪽 sticky 재생 패널이다. |
| 중간 | 활성 문장 이벤트·장면 동기화 | 실제 DOM 문장을 넘기는 tiger-active-sentence 이벤트, 문장 클릭 탐색, 그림 교체, reduced-motion, 수동 스크롤 4.5초 유예가 없다. |
| 중간 | Whisper 시간 연결 | 단어 타이밍·독립 ASR 검증이 없다. 현재는 문장 강조도 아닌 문단 강조다. 근거 없이 단어 시간을 만들면 안 된다. |
| 중간 | 공통 설치 | player.js는 1장만 로드한다. 나머지 장에 오디오가 없는 것은 정상이나 공통 독서 모드는 전체 페이지에 설치되지 않았다. |
| 중간 | 재생성 보존 | 연결은 현재 chapter-01.html와 전용 importer에 있다. 다른 페이지 생성 경로에서 동일 연결을 보존하고 문장 맵을 검증하는 계약은 없다. install_cleanroom_novel.py는 페이지를 파싱하므로 반드시 삭제된다고 단정하지 않는다. |
| 중간 | 오프라인 | 서비스 워커·파일 검증 저장/책 범위 삭제·Range·CORE/SAVED 업데이트 검사가 없다. |
| 미검증 | 음성 내용·실기기 | 디코딩과 브라우저 재생은 실제 청취 검수를 대신하지 않는다. 대본대로 들리는지, 감정·배역·독백 잔향, 휴대폰 잠금·회전·이어폰은 미검증이다. |

## 적용 순서

1. 검토 결과를 별도 고정하고 생성기의 자동 confirmed 변경 제거. 기존 승인·문장·색인은 보존.
2. DOM 문장/문단 ID와 음성 manifest를 정확히 연결하고 재생성·원고 변경 감지 검사.
3. 화자 음량·경계 무음 측정, 독백 효과 이력 확인 및 실제 표본 청취. 추정 DSP 중복 적용 금지.
4. 기존 단일 재생기를 유지하며 정밀 이어듣기·문장 강조·활성 이벤트 추가.
5. 공통 가로모드와 전체화면, 삽화 동기화·설정 UI를 전체 읽기 페이지에 적용.
6. 오프라인·한국어 정렬·실기기를 각각 검증하고 적용 범위를 구분하여 배포.

일반 Canvas HTML 생성 경로와 공개 코드 복사 기능은 이미 통과했다. 포털의 선택적 다운로드 버튼 숨김은 사용자의 ‘코드 복사 버튼만’ 지시에 따른 예외이며 Canvas 실행 HTML을 수작업 변형한 것이 아니다.

기계 검사: skill-integration-audit.json, skill-audit-copy-browser.json, chapter-01-audio-browser.json. 자동 검토 통과 표시를 독립적인 편집 승인이나 청취 승인으로 해석하지 않는다.

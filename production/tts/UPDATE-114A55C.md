# 오디오북 스킬 후속 반영

동일 문단 컷 편집은 호환 재생 경로에 부분 적용돼 있었다. 새 문단 시작에도 trim_start를 적용하던 문제를 수정해 문단 내부 경계만 자른다. 새 문단의 시작·끝 쉼은 원음 그대로 보존하고 문단 간 350ms 간격을 둔다. 원본 60개 MP3는 수정하지 않는다.

timeline.js에서 원음 시각·유효 구간·장 offset을 한 번 계산한다. 화면 이벤트는 같은 기준을 사용한다. 문단 전환 대기 중 정지하면 예약 전환을 취소한다. 클립 변경 때 restoring 상태를 재설정해 이전 클립 저장 경합을 방지한다. timeupdate 기반 호환 경로이므로 샘플 단위 무간격 편집을 보장하지 않는다. 정밀 엔진과 실청취 평가는 후속 범위다.

추가 반영: 84페이지 독서 진행선·오디오와 독립된 문단 이어 읽기·설정집 링크, PWA manifest/192·512 아이콘/설치 이벤트, 1장 문맥 어휘 카드 2개. 어휘 버튼은 음성 문장 클릭으로 전파되지 않으며 원문 textContent를 유지한다.

배역 고정: voice_identity.py가 1·2장 전체 230문장의 성우와 기본 페르소나를 배역표와 비교한다. 변경 시 제작 차단. 실제 음색 청취 검증은 별개이며 두 목소리로 들리는 현상까지 해결했다고 주장하지 않는다.

미완료: 전편 문맥 어휘, 한국어 Whisper 단어 정렬·독립 ASR, 여러 장/부 선택 저장과 트랜잭션 캐시, 정밀 클립 엔진, 실기기 설치·잠금 재생·청취. 단어 시간은 추정해서 채우지 않는다.

검증: test_timeline.cjs, cut-reading-browser.json, reader-integration-browser.json, VOICE-IDENTITY-AUDIT.json. 실제 원음 청취와 물리 기기 시험은 미실시.

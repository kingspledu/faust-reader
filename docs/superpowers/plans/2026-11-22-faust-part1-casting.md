# 제1부 전체 성우 오디션 계획

이 계획이 이전의 제1장 한정 오디션 범위를 대체한다. 계획 수립 단계이며 실제 HTML·음성 생성이나 기존 배역표 변경은 하지 않았다.

## 기준과 전체 배역

제1부 28장 전체를 대상으로 한다. 현재 `voice-cast.json` 133항목, TTS 색인 1,853구간에 실제 발화 배역 39개가 있다. 0구간인 나머지 94항목에는 비발화로 등록된 4항목도 포함된다. 이 숫자는 기존 대본의 현황이지 원문 전체 배역 대조가 완료됐다는 뜻이 아니다.

- [전체 배역표](2026-11-22-faust-part1-audition-roster.md): 133항목을 발화/대조 대기/비발화로 구분.
- [오디션 입력 목록](2026-11-22-faust-part1-audition-roster.json): 실제 대사·장·장면·구간 ID·본문 해시·기존 페르소나 포함.

**필수 선행:** 원문 발화자 → 게시 각색문의 대사/독백 → TTS 구간을 대조한다. 0구간인 대천사 등은 이름만 보고 단역 오디션에서 제외하지 않는다. 나레이터가 대신 읽게 잘못 매핑된 경우에는 본문 문구를 임의로 바꾸지 않고 화자 분리·배역 연결을 수정한다. 서술로 처리된 원문 대사는 편집 검토 대상으로 기록하며 성우 계획 때문에 원고를 몰래 재각색하지 않는다. ‘다른 이’·‘학생’·‘모두’ 같은 동명이칭은 장면 문맥으로 분리한다. 수정 후 아래 수치와 요청 수를 재집계한다.

## 단계별 오디션 규모

| 구분 | 현재 배역 수 | 후보/배역 | 문항/후보 | 원음 생성 수 |
|---|---:|---:|---:|---:|
| 주요: 나레이터·파우스트·메피스토·그레첸 | 4 | 4 | 4 | 64 |
| 조연: 현재 3구간 이상인 나머지 배역 | 17 | 3 | 2 | 102 |
| 단역·합창: 현재 1~2구간인 배역 | 18 | 2 | 1 | 36 |
| 합계 | 39 | — | — | **202** |

이것은 현재 색인 기준 1차 견적이다. 전부 한꺼번에 생성하지 않고 주요 64개를 먼저 확보·선발한다. 0구간 대조에서 추가 발화자가 확인되면 해당 단계에 포함하며, 기존 목록을 누락으로 확정하거나 완료 수치로 사용하지 않는다. 시인·주·악령 등 적은 대사라도 극적 중요도가 높으면 문항 추가 가능하되 수량 변경을 기록한다.

## 주요 배역 페르소나·후보·시험 장면

후보 이름은 Gemini 사전 정의 음색 ID다. 음색의 실제 한국어 성별 인상·나이·연기 적합성은 청취로 판단한다. 특정 배우의 목소리를 모방하지 않는다. 기존 임시 배역은 비교 후보에 포함한다.

| 배역 | 제안 후보 | 페르소나 | 4개 시험 톤 |
|---|---|---|---|
| 나레이터 | Charon / Sulafat / Schedar / Kore | 친절하고 또렷한 전지적 서술자. 감정은 장면을 돕되 청자에게 강요하지 않음 | 1장 도입 / 대화 사이 상황 연결 / 밝은 일상 / 감옥의 긴박함을 절제한 설명 |
| 파우스트 | Orus / Charon / Alnilam / Iapetus | 지적 질문·조급함·갈망·후회가 공존. 회춘 전후 같은 배우, 속도·활력만 변화 | 학문의 회의 / 메피스토에게 반박 / 그레첸에게 조심스러운 말 / 마지막 절박함과 책임 |
| 메피스토 | Fenrir / Algieba / Umbriel / Achird | 느긋하고 능청스러움. 파우스트에게 반말, 타인에게 공손한 척. 괴물 소리·반복 킬킬거림 금지 | 파우스트와 티키타카 / 주 앞의 빈정거리는 정중함 / 마르테 앞의 사교적 위장 / 급박한 상황의 차가운 현실 판단 |
| 그레첸 | Leda / Aoede / Zephyr / Vindemiatrix | 자기 생각을 가진 인물. 수줍음만으로 축소하지 않음. 관계·불안·죄책감·마지막 결심을 연결 | 첫 만남의 단호한 거절 / 가까워진 뒤 친근함 / 종교·관계에 대한 진지한 질문 / 감옥의 두려움과 결심 |

각 문항의 정확한 대사는 입력 목록에서 고르고, source segment ID와 해시를 고정한다. 감정에 맞는 대사가 없으면 새 대사를 만들지 않고 대조 필요로 표시한다. 여러 화자의 관계 시험은 한 요청 안에서 후보를 뒤섞지 않고, 확정된 상대역 음성에 시험 후보를 차례로 연결해 비교한다.

## 조연·단역 운영

조연 17배역은 마르테·극장 지배인·극작가/시인·바그너·학생·희극 배우·리스헨·주·프로슈·지벨·알트마이어·마녀·브란더·발렌틴·대지의 정령·수컷 원숭이·악령이다. 각 배역은 현재 음색 + 대비되는 2후보로 구성하고, 후보 ID는 생성 전 배역별로 명시한다. 전 배역에 같은 후보 3개를 기계적으로 복사하지 않는다.

문항은 평소 말투 하나와 가장 다른 감정/사회적 관계 하나를 택한다. 예: 마르테의 생활감/사교적 떠보기, 바그너의 공손한 질문/학문적 자신감, 발렌틴의 분노/상처, 악령의 낮고 명확한 압박. 악령·정령이라고 자동 왜곡·에코를 넣지 않는다.

단역·합창 18배역도 사용자가 선택한다. 원문 대사가 한 문장이면 같은 문장을 두 후보로 비교하고 분량을 늘리려고 대사를 창작하지 않는다. 합창은 먼저 대표 낭독 음색을 선발한다. 실제 다중 합창·노래 생성과 같은 것으로 표시하지 않는다. 공동 발화는 기존 배역의 조합이며 새 인물을 만들지 않는다.

동일 음색의 겸역은 허용하되 같은 장면에서 대화하는 배역끼리는 구별되는지 확인한다. 음색을 1인 1역으로 강제해 부자연스러운 후보를 고르거나, 인물 ID를 합치지 않는다. 주요 4배역은 우선 서로 구별되는 음색 조합으로 선발한다. 헌시의 시인과 극장 서막의 시인은 별도 배역으로 유지하고 겸역은 사용자가 선택할 수 있다.

## 연기 규격

- 한국어 현대 대화 리듬. 역할명·지문·괄호 설명·독백 라벨은 읽지 않음.
- 맥락/말의 목적/감정 변화/호흡을 구간별로 기록. 일률적인 ‘슬프게’·‘극적으로’ 지시 금지.
- 같은 역할·문항의 비교는 모델·대본·프롬프트·후처리를 고정하고 음색만 변경한다. 재생성 take는 따로 보관해 좋은 take만 임의 선별한 비교를 피한다.
- 1차는 dry로 음색 선발. 독백만 같은 take에 승인된 echo-v4·짧은 리버브 적용본을 추가해 비교한다. 속삭이지 않는 나직한 유성 발화. 효과본 때문에 TTS 요청을 추가하지 않는다.
- 웃음·울음·호흡은 원문·각색문 맥락이 있는 시험에만 소량. 기침·비명 등 새 사건을 창작하지 않는다. 극단 연기 하나만으로 성우를 고르지 않는다.
- 한국어 발음·본문 일치·잡음·클리핑·음색 변화·불필요한 비언어음 검수. 비교 음량 보정본과 원본을 구분한다.

## 선택 페이지

`audition/index.html`: 주요인물 / 극장 / 하늘과 정령 / 그레첸 주변 / 술집 / 마녀와 산의 밤 / 단역과 합창 메뉴. 배역 검색, 첫 등장 장, 발화 구간 수, 오디션 준비·선택 상태 표시. 그레첸 등 여러 그룹에 걸친 배역은 하나의 cast_id로 연결한다.

배역마다 페르소나 → 실제 발췌 대사·연기 의도 → 후보 A~D 비교 → 점수·메모 → 1순위/예비 선택 순서다. 기본 블라인드이며 음색 이름은 펼쳐 확인한다. 같은 문항 A/B 전환, 구간 연속 듣기, 원음/독백효과 비교, 중복 재생 방지, 선택 JSON 저장·불러오기 제공. 선정된 주연끼리의 대화 조합 확인 화면을 둔다.

선택은 브라우저 로컬에 저장하고 파일로 내보낸다. 자동 원격 저장이나 공개 투표로 오해하게 하지 않는다. 배역표를 자동 덮어쓰지 않는다. 전체 배역 선택 후 사용자가 확정한 결과만 적용한다. 미생성·미선택·원문 대조 대기·비발화 상태를 구분한다.

## Canvas 생성 HTML

기존 `gemini-canvas-tts` 템플릿을 적용한다. API 키 직접 입력 없는 Canvas 호스트만 사용하고, 기존 `gemini-2.5-flash-preview-tts`와 후보 지원을 첫 실제 요청으로 검사한다. 지원되지 않으면 이유를 기록하고 다른 모델로 자동 변경하지 않는다. 새 세대 전용 태그를 2.5에 섞지 않는다.

202요청을 하나의 거대한 HTML에 넣지 않고 **배역별 HTML 39개 + 전체 실행 색인 페이지**로 만든다. 주요역은 HTML당 16요청, 조연은 6요청, 단역은 2요청이다. 실제 수량은 배역 대조 후 재산출한다. 요청은 한 번에 하나씩, 실패만 재시도·중단/재개·누락 목록·개별 다운로드를 지원한다.

파일명 예: `FAUST_P1_AUD02_FAUST_ORUS_Q01_T01_DRY.wav`. 배역/후보/문항/take/효과를 포함하고, 색인에는 모델·본문/프롬프트 해시·출처 장/장면·cast_id·상태를 저장한다. 장 번호 하나로 범위를 오해하지 않게 전편 오디션 버전 `AUD02`를 사용한다. 기존 `AUD01` 계획과 실제 본편 V04 음성과 섞지 않는다.

## 실행 순서와 산출물

1. 133항목의 원문·게시문·TTS 배역 대조를 마치고 실제 낭독 배역 목록 확정.
2. 배역별 페르소나·정확한 문항·후보 ID·연기 프롬프트·출처 해시 확정.
3. 주요 4역의 생성 HTML과 선택 페이지를 먼저 구현·자동 검사.
4. Canvas 실제 음성 1개 생성·청취·다운로드 확인 후 주요 64개 확보.
5. 사용자 주요역 선발·대화 조합 검사. 같은 배역의 장별 음색과 회춘 전후 정체성 유지 확인.
6. 조연·단역 HTML을 순차 제작해 실제 음성 확보·사용자 선발. 대조 대기 배역 추가 시 수치 갱신.
7. 필요시 주요역 상위2후보×2문항 결선: 최대16개 추가 원음. 자동 실시하지 않고 1차로 판단 어려운 역할만 적용.
8. 전체 선택 JSON을 검증해 새 CAST revision으로 배역표 갱신. 기존 전체 본편 음성 재생성은 별도 후속 제작.

산출물: 전체 배역 목록/JSON, 배역별 오디션 대본·연기표, 생성 HTML 및 전체 색인, 비교·선택 웹페이지, 음성 수입/누락 검증 도구, 사용자 선정 결과·확정 배역표. 생성 요청 수와 실제 확보·청취·선정 수는 별도로 보고한다.


## 문장별 음성 제작 필수 규칙

한 문장 = 한 생성 요청 = 한 개별 WAV/MP3다. 문단 전체나 배우가 이어 읽을 여러 문장을 한 요청으로 묶지 않는다. 배포 ZIP은 개별 문장 MP3를 유지한다. 합본은 선택적 청취 파생물이며 문장 파일을 대체하지 않는다.

각 segment는 sentence_id, paragraph_id, context_before/context_after(문장 ID 배열), 문장별 performance.sentence_persona, performance.design을 가진다. 기본 배역 페르소나는 유지하되 해당 문장의 상대·목적·현재 감정을 별도로 적용한다. 같은 문단의 분위기·호흡을 이어 주며 분리 생성한다.

앞뒤의 ‘울부짖었다·웃었다·울었다’ 같은 묘사를 읽고 누구의 어느 발화에 적용되는지 찾는다. performance.cue_links에 source_sentence_id, target_sentence_id, cue_text, instruction을 기록한다. 해당 단서가 없으면 빈 배열로 명시한다. 단서가 다른 인물/시점이면 억지로 적용하지 않는다. 웃음·울음의 강도·위치는 근거에 맞추며 기계적으로 덧붙이지 않는다.

검토는 speaker_pass, cue_pass, continuity_pass의 세 항목으로 각각 기록한다. review.evidence와 review.sentence_boundary_evidence에는 실제 문맥·분할 근거를 적는다. 생성기나 정규식이 검토를 confirmed로 자동 변경해서는 안 된다. 화자가 애매하면 review.attribution=user_review_required로 두고 질문 대상 문장·앞뒤 문맥·후보·판단 근거를 사용자에게 제시한다. 승인 전 그 문장은 생성 차단한다. 나레이터로 임의 대체하지 않는다.

문장 분할 시 인용부호·약어·소수·말줄임표·감탄사에 주의한다. 문장 경계의 자동 탐지는 보조 검사일 뿐 의미 검토가 아니다. 기존 문단의 문자 범위와 문장 순서를 유지하며 누락·중복을 대조한다. 이전 문단형 대본은 신규 문장 검토 전까지 생성 불가 초안이다.

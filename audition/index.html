음성 생성과 비교 방법
  1. 위 버튼으로 39배역·202개 대사가 담긴 통합 HTML 코드를 복사해 Gemini Canvas에 붙여 넣습니다. API 키를 입력하지 않습니다.
  2. 우선 한 구간을 생성해 실제 재생·WAV 다운로드를 확인한 뒤 나머지를 생성합니다.
  3. 내려받은 WAV들을 아래에서 선택합니다. 파일은 서버에 업로드되지 않습니다.
  4. 후보를 비교하고 1순위·예비를 저장한 뒤 선택 결과 JSON을 내려받습니다.

HTML은 음성을 포함하지 않습니다. Canvas 호스트의 모델·음성 생성 권한이 지원되지 않으면 생성이 실패할 수 있습니다. 다른 모델로 자동 전환하지 않습니다.

# 최신 스킬 반영 기록

`catalog.json`의 skill_revision으로 kingspledu/audiobook-reader-skill을 `.tools/`에 준비해 사용한다. 도구 폴더는 배포하지 않는다. 재생성 진입점은 `python build_auditions.py`다.

수정하지 않은 `copy_site.render_episode()`와 단일 Canvas 템플릿으로 통합 HTML을 렌더링했다. `build_copy_site()`로 파일 크기·SHA-256 manifest와 코드 복사 사이트를 만들었다. 오디션 포털에는 기존 요청대로 통합 코드 복사 버튼 하나를 유지하며 같은 manifest로 검증한다. 복사 권한이 없으면 코드 전체를 선택한다.

68개 문항의 게시 HTML 화자·발화 종류를 대조하고 문항별 발화 목적, 겉감정/속마음, 전환, 운율, 비언어, 호흡을 작성했다. 후보 반복을 포함한 202구간에 동일하게 전달된다. 기존 원문 대조 대기 94항목을 자동 확정하지 않았다. 후보 표시명만 ‘원래 화자 · 음색 후보’로 구별하고 source_speaker/cast_id/본문을 보존했다.

최신 템플릿의 독백 효과 적용에 맞춰 독백 파일명을 ECHO_V4로 표시했다. 비교 플레이어는 이 파일에 효과를 다시 적용하지 않는다. 예전 DRY 이름의 독백 파일을 새 효과본으로 오인해 불러오지 않는다.

Chrome 시험: 정확한 전체 HTML 복사,404·해시 불일치 거부,복사 거부 시 수동 선택,포털 선택 저장,모바일 가로 넘침 없음,JS 오류 없음. 202구간의 템플릿/대본/색인·DSP·모의 일괄 생성 검사 통과.

스킬 검증기는 시험용으로 두 부분을 보완했다. 단일 파일이라 오류 시험 뒤 명시적으로 재선택하고, 기존 오디션 파일명을 보존하기 위해 episode의 파일명 집합으로 색인을 찾는다. 제품 렌더러/템플릿은 수정하지 않았다. 복수 장 빠른 전환은 단일 파일이라 해당 없음이다.

실제 Gemini Canvas 생성·음성 다운로드·사람 청취는 미검증이다. 코드 복사 통과를 음성 품질 검증으로 보고하지 않는다.

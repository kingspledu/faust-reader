# 파우스트 제1부 성우 오디션 AUD02

현재 대본의 39배역, 후보별 202개 원음 생성 요청을 준비했다. 실제 음성 파일은 포함하지 않는다. 기존 성우 배정은 변경하지 않았다. 원문 대조 대기 94항목은 완료/제외로 처리하지 않는다.

1. `index.html`을 HTTP(S)로 열고 주요인물부터 선택한다.
2. 배역별 Canvas HTML을 다운로드해 Gemini Canvas에 올린다. 키를 입력하지 않는다. 먼저 1구간 실제 생성/재생/다운로드를 확인한다. 호스트나 모델이 음성을 반환하지 않으면 미지원 오류를 기록하고 다른 경로로 우회하지 않는다.
3. WAV 파일을 페이지의 ‘음성 파일 연결’에서 선택한다. 파일명은 `AUDITION_INDEX.json/csv` 기준이다. 파일은 업로드하지 않는다. 이름 일치는 실제 대사 정확도나 오디오 무결성 보증이 아니며 디코딩과 청취가 필요하다.
4. 후보 A~D를 같은 문항으로 비교하고 평점·메모·1순위·예비를 저장한다. 독백 효과는 같은 원음에 적용한다.
5. 선택 결과 JSON을 내려받는다. 새로고침 후 음성 파일은 다시 선택한다. 로컬 평가는 브라우저 데이터 삭제로 없어질 수 있다.

자동 검증: `python -X utf8 verify_audition_build.py`, `node test_audition_ui.cjs`. 후자는 DOM 모의 시험이며 실제 브라우저/음성 생성/다운로드 시험을 대체하지 않는다. 현재 브라우저 연결 호스트가 없어 실화면·실오디오 검증은 미완료다.

본문은 게시 각색문에서 그대로 발췌했다. 역할별 후보·문항 수는 계획 기준이며, 최종 선정과 본편 음성 제작 전에 원문/게시 대사/화자 매핑의 전체 대조가 필요하다. 특히 조연의 연기 지시는 현재 페르소나와 실제 발췌를 기반으로 한 초안이다.

# 파우스트 제1부 오디션

사이트 상단에서 전체 HTML 코드를 복사해 Gemini Canvas에 붙여 넣는다. 39배역·202개 요청이 하나의 HTML에 들어 있다. API 키를 직접 입력하지 않는다.

최신 스킬의 공통 렌더러, 단일 템플릿, 파일 크기·SHA 검증, 클립보드 차단 시 수동 전체 선택을 적용했다. 실제 생성은 한 구간의 재생·다운로드부터 확인한다. Canvas 호스트가 지원하지 않으면 실패를 기록하고 다른 API 경로로 우회하지 않는다.

독백 파일은 최신 템플릿에서 짧은 에코를 적용하므로 ECHO_V4 이름으로 저장된다. 이전 DRY 독백 파일과 섞지 않는다. 비교 페이지는 효과를 중복 적용하지 않는다. 대사·나레이션은 DRY다.

생성 파일을 비교 페이지에서 연결하고 후보를 선택한다. 선택은 브라우저 로컬 저장이며 JSON으로 내보낼 수 있다. 본편의 배역표를 자동 변경하지 않는다. 94항목의 원문 대조 대기·비발화 등록 상태를 유지한다.

세부 검증과 도구 버전은 SKILL_UPDATE.md, skill-review.json, copy-browser-report.json, portal-browser-report.json에 기록한다. 실제 음성 생성·사람 청취는 아직 검증하지 않았다.
